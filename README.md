# Quest — Issue 01

A digital magazine, catalog and open-world guidebook: world-class things to do in life.

- `index.html` — the world map, guidebook, catalog, casting board and skills/tokens economy (single file, no build step)
- `guide.html` — standalone guidebook
- `img/`, `vid/`, `fonts/` — assets

Open `index.html` in a browser, or serve the folder with any static host.
